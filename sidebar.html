Troubleshooting

If you get permission errors, try these steps:
To authorize the script:
1. Go to Extensions → Apps Script
2. In the Apps Script editor, look for a 🔒 lock icon or "Review Permissions" button at the top
3. Click it and authorize the script
4. OR: Select testAuthorization from the function dropdown and click Run (▶️)
5. Click "Review Permissions" when prompted
6. Come back here and try again
